# Interactive Maps Project Rules

## Enterprise Scale & Standards

- **Project Scope:** Treat this codebase as an enterprise-grade platform. Features must be heavily planned out across long sprints (minimum 20 sprints for full delivery).
- **UI/UX Excellence:** Do not neglect the frontend. Use modern React 19 standards, animations, and high-fidelity design. Always apply modern web guidance (e.g., View Transitions, Glassmorphism) and the `impeccable` skill for visual hierarchy and UX copy.
- **Enterprise Map Features:** The MapLibre engine must support enterprise capabilities (e.g., 3D terrain, WebSockets for live driver tracking, offline caching, clustered data rendering).
- **Monitoring & Hardening:** All features must include telemetry, comprehensive error boundaries, and security monitoring.
- **Agent Tooling:** Actively leverage `modern-web-guidance`, `impeccable`, and the `agency-agents` ecosystem to build and audit these features.
